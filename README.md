# Proyecto Node.js + Express API

Aplicación backend modular desarrollada con Node.js y Express, estructurada bajo buenas prácticas de desarrollo de software, gestión de dependencias con npm, configuración de variables de entorno seguras con dotenv y control de versiones con Git.

---

## Tecnologías y Dependencias

- **Entorno de ejecución:** Node.js
- **Framework Backend:** Express.js (v4.21.2)
- **Gestión de Entorno:** Dotenv (v16.4.7)
- **Herramienta de Desarrollo:** Nodemon (v3.1.14)
- **Control de Versiones:** Git & GitHub

---

## Estructura del Proyecto

```text
node-express-app/
├── node_modules/         # Dependencias instaladas (ignorado por Git)
├── .env                  # Variables privadas de entorno (ignorado por Git)
├── .env.example          # Plantilla pública de variables requeridas
├── .gitignore            # Reglas de exclusión de archivos para Git
├── index.js              # Servidor principal, middlewares y rutas
├── package.json          # Metadatos del proyecto y scripts de ejecución
├── package-lock.json     # Árbol exacto de dependencias instaladas
└── README.md             # Documentación técnica del proyecto
```
